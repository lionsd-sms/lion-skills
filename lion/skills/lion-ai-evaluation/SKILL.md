# AI 활용과 평가

AI가 할 일이 창작·요약·분류·추출·추천·계산·실제 실행 중 무엇인지, 누가 결과를 어디에 쓸지, 틀렸을 때 무엇이 달라지는지 정한다. 정밀 계산·현재 사실·현장 판단은 결정적 도구나 원자료 확인이 더 적합한지 본다. AI 사용 자체를 별도 위험 관리 사업으로 만들지 않는다.

입력의 대표성·품질·필요 범위·처리 권한을 확인한다. 학습·미세조정·검색 색인·추론·평가 자료는 용도와 저장·재사용 조건이 다르다. 데이터셋의 모집단·기간·중복·라벨 품질과 훈련/평가 누수를 확인하고, 성능이 좋아 보이도록 시험 분할을 다시 고르지 않는다. 비공개 입력을 외부 모델에 보내는 동작은 승인된 처리 범위 안에서 하고, 로컬 실행도 저장·로그·결과 노출을 살핀다. 실제 모델 사용 여부·판본을 확인하지 못했으면 추정으로 남긴다.

그럴듯한 허위, 누락, 단위 오류, 편향, 지시가 섞인 입력을 살핀다. 요약은 중요한 조건·부정·의무·예외가 보존되는지, 추출은 원문에 없는 값을 채우지 않았는지 확인한다. 출력은 검증할 자료이며 권한 있는 명령으로 바로 실행하지 않는다. 자동 적용 여부, 실패·불확실·거절 때의 상태, 돈·권리·안전에 닿는 결과의 권한과 확인 경로를 정한다. 사용자가 오류를 알아차리고 고칠 길도 마련한다.

평가 전에 실제 업무를 대표하는 정상·경계·실패 입력과 **독립 기대 결과**를 정한다. 누락·거짓 긍정·거짓 부정·의미 보존·수정 비용 등 맡긴 일에 맞는 척도를 쓴다. 확률적 결과는 변동과 실패 분포를 함께 보고, 한 번의 성공을 안정성으로 보고하지 않는다. 합성 예시와 실제 관찰을 구분하고 시험 로그에 개인정보를 불필요하게 남기지 않는다. 모델·프롬프트·검색 자료·출력 파서가 바뀌면 영향을 받는 평가를 같은 입력·권한·환경·판정 기준에서 다시 수행한다. 형식 통과와 업무 성공을 구분한다. 형식만 맞추도록 강제해 실제 오류를 숨기거나, 근거 없는 신뢰도 수치·자체 점수로 원문 대조와 업무 검증을 대신하지 않는다. 한 번의 좋은 답으로 일반 성능을 주장하지 않는다. 운영의 실패·거절·사용자 수정·지연·비용 신호와 사람 검토는 실제 확인한 범위만 보고한다.
