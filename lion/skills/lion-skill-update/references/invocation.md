# 열림 문구

SKILL.md의 「작성 핵심」에 더해 frontmatter·description을 쓰거나 고칠 때, 사람이 이름으로만 부를 스킬과 모드 방식 저장소의 호출 방식을 정할 때 쓰는 기준이다.

## 1. frontmatter와 호출 방식

- `name`: 소문자와 하이픈, 폴더 이름과 같다.
- `description`: SKILL.md 「작성 핵심」의 꼴을 따른다.
- 모드 방식 저장소(모드 스킬 하나만 자동으로 열리고, 그 스킬의 「함께 여는 스킬」 표가 나머지를 연다)면 이 항목만 따르고 아래 호출 방식 항목은 건너뛴다.
  - 모드 밖 스킬은 자동 선택을 끈다: Claude 는 frontmatter 에 `disable-model-invocation: true`, Codex 는 `agents/openai.yaml` 에 `policy.allow_implicit_invocation: false`. description 은 그대로 둔다. description 은 모드 표 한 줄의 원천이고 사람이 보는 메뉴에 남는다.
  - 새 스킬은 모드 표에 한 줄을 더한다. 줄에는 열릴 요청 갈래를 쓰고, 이웃 줄과 같은 요청을 다투면 「…은 빼고」를 붙인다.
  - 모드 표는 맞는 줄을 모두 여는 표가 아니라 가장 맞는 줄 하나를 고르는 표다. 그래서 모드의 「함께 여는 스킬」 첫 줄만 본문 구조 기준의 정해진 첫 줄 대신 "아래 표에서 「바로 할 일」 1번대로 고른 스킬을 … 연다"로 둔다. 맞는 줄을 모두 열게 두었던 판에서 계획 스킬이 다른 스킬 문장 18건에서 같이 열렸다(2026-10-20).
  - 모드는 꺼 둔 스킬을 도구 호출이 아니라 `<이름>/SKILL.md` 파일을 읽어 연다. Claude 는 자동 호출을 끈 스킬을 Skill 도구로 부르면 막고 다른 방법으로 따라 하지 말라고 알려, 도구로 부르게 쓰면 일이 멈춘다.
  - 열림을 고칠 곳은 모드 표의 줄이고, 모드 자체가 안 열리는 요청이면 모드 description 과 세션 시작 훅 글이다.
  - 모든 일에 지킬 행동은 모드의 참고 파일 하나에 두고 모드 단계에서 바로 읽게 한다. 늘 읽는 파일이라 「필요할 때만 더 읽기」 표에 두지 않는다.
  - 일을 맡긴 서브는 세션 시작 훅을 받지 않는다. 그래서 맡기는 쪽이 지시서에 읽을 스킬의 SKILL.md 경로를 적는다.
- 호출 방식은 "AI가 스스로 집을 만한 일인가"로 정한다. 그렇다면 AI가 스스로 고르는 스킬이다. 이 스킬은 description이 모든 대화의 목록에 실려 자리를 차지하므로, 낱말마다 열림에 쓰이는지 본다.
- 손으로만 부를 일이면 사람 호출 전용으로 두어 목록 자리를 비운다. 대신 사용자가 그 스킬이 있다는 것을 기억해야 하므로 사람 호출 전용이 쌓이면 기억 부담이 커진다.
- 사람이 이름을 쳐서만 부를 스킬은 자동 선택을 끈다.
  - Claude: frontmatter에 `disable-model-invocation: true`를 더한다.
  - Codex: 스킬 폴더의 `agents/openai.yaml`에 `policy.allow_implicit_invocation: false`를 둔다(기본은 켜짐).
  - 이때 description은 사람이 읽을 한 줄 요약으로 쓰고 말투 예는 뺀다.

## 2. description 세부

- description은 늘 목록에 실려 있는 안내문이다. 무엇인지와 어떤 갈래에서 열려야 하는지 두 가지를 쓴다.
- 이 스킬을 대표하는 낱말을 앞에 둔다. 사용자가 실제로 쓰는 낱말이면 더 잘 열린다.
- 말투 예는 서로 다른 갈래마다 하나다. 같은 갈래의 동의어는 하나로 줄이고 남은 자리에 다른 갈래를 넣는다.
- 본문이 이미 하는 설명(정체 소개, 원칙)은 description에서 뺀다.
- 절차 순서는 본문에만 둔다. description에 순서가 있으면 AI가 본문 대신 그 요약을 따른다.
- 범위 밖은 그 상황을 말로 쓴다("한 프로젝트의 결정 기록 정리").
- 꼭 읽혀야 할 내용이 약한 description 뒤에 있어 열리지 않으면 description의 낱말을 먼저 날카롭게 한다. 그래도 열리지 않을 때만 그 내용을 항상 읽히는 문서에 직접 둔다.
