# 다듬기 전후 대조

긴 글과 숫자가 많은 글은 눈 대조에 더해 아래 스크립트로 숫자와 인용을 맞춘다.

## 긴 글은 스크립트로 숫자와 인용을 맞춘다

원문과 고친 글을 UTF-8 파일 두 개로 두고 실행한다. 숫자 표기, 백틱 코드, 따옴표 인용을 세어 빠진 것과 생긴 것을 보인다. 숫자 끝의 문장 부호(`1.2.`의 마침표, `1,`의 쉼표)는 떼고 센다. 낱말 사이의 아포스트로피(`doesn't`)는 인용으로 세지 않는다.

```python
import re, sys
from collections import Counter

sys.stdout.reconfigure(encoding="utf-8")
NUM = r"\d+(?:[.,:/~-]\d+)*"
QUOTE = r"`[^`\n]+`|\"[^\"\n]+\"|“[^”\n]+”|(?<!\w)'[^'\n]+'(?!\w)|「[^」\n]+」"

def keep(path):
    text = open(path, encoding="utf-8").read()
    return re.findall(NUM, text), re.findall(QUOTE, text)

(bn, bq), (an, aq) = keep(sys.argv[1]), keep(sys.argv[2])
before, after = Counter(bn + bq), Counter(an + aq)
print("빠짐:", dict(before - after))
print("생김:", dict(after - before))
common = [n for n in bn if n in an]
if common != [n for n in an if n in bn]:
    print("숫자 순서 다름:", bn, "->", an)
```

'빠짐'과 '생김'이 모두 비어야 한다. 비지 않으면 그 항목을 원문 문장과 맞춰 되돌리거나, 일부러 지운 것이면 보고에 까닭을 적는다. '숫자 순서 다름'이 나오면 그 문장을 짝지어 뜻이 같은지 본다(날짜를 문장 뒤로 옮긴 것은 같고, `40분에서 15분`이 `15분에서 40분`이 된 것은 다르다).

스크립트가 맞추는 것은 숫자 표기와 인용뿐이다. 순서(`줄었다`↔`늘었다`), 부정(`없다`↔`있다`), 한글 수(`셋에서 둘로`), 이름, 용어, 주어는 원문 문장마다 고친 문장을 짝지어 맞춘다. 짝 없는 고친 문장에는 원문에 없는 사실이 들어갔는지 본다.

대조 결과를 한 줄로 쓴다. 예: `숫자 12개·이름 5개·인용 2개 그대로. 지운 문장 3개(12·13·16).`

## 새로 생긴 티

대조가 끝나면 고친 글에 티 목록을 한 번 더 훑는다. 고치다 새로 생긴 티(번역투를 고치다 생긴 어미 섞임, 단서를 지우다 생긴 단정)를 잡는다.

## 대조표

사용자가 바꾼 까닭을 보자고 하거나 바꾼 문장이 많으면 대조표를 붙인다.

| 원문 | 고친 글 | 번호 |
|---|---|---|
| 점검 시간이 크게 단축되었으며 | 점검 시간은 줄었습니다 | 2 |
| 이는 효율성 향상에 기여할 것으로 기대됩니다 | (지움) | 13 |
