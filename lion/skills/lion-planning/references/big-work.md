# 여러 세션에 걸친 큰 일

한 세션에 담기지 않고, 앞 결정이 풀려야 다음 결정이 보이는 일에 쓴다. 넓게 훑어도 정할 것이 몇 개뿐이고 끝까지 가는 길이 보이면 결정 목록 없이 보통 계획으로 간다.

## 결정 목록 파일

계획을 둘 곳에 파일 하나로 둔다.

```
도착점          : 이 일이 끝나면 생기는 것(명세, 굳힐 결정, 실제 변경) 한두 줄
정한 결정       : 결정 이름 · 한 줄 요약 · 자세한 내용이 있는 곳
열린 결정       : 결정 이름 · 질문 · 종류 · 먼저 풀려야 할 결정 · 맡은 세션
아직 못 정한 것 : 다가오는 것은 보이지만 아직 질문으로 쓰지 못하는 것
범위 밖         : 도착점 너머로 뺀 것과 까닭
```

- 열린 결정 하나는 정할 질문 하나다. 만들 조각은 적지 않는다.
- 질문을 지금 정확히 쓸 수 있으면 열린 결정에 둔다. 아직 못 쓰면 「아직 못 정한 것」에 둔다. 그곳의 항목을 미리 잘게 나누지 않는다.
- 결정 내용은 한 곳에만 쓰고, 목록에는 요약과 위치만 둔다.
- 사람이 읽는 곳에서는 결정을 이름으로 부른다.

## 결정의 종류

| 종류 | 푸는 방법 |
|---|---|
| 조사 | AI가 혼자 문서 · 자료에서 사실을 찾는다. 서로 무관한 조사는 함께 돌린다 |
| 시안 | 시안을 보여 주고 사용자가 고른다 |
| 질문 | 사용자에게 묻는다. 기본 종류다 |
| 사전 작업 | 결정에 필요한 준비(계정 만들기, 자료를 옮겨 모양 보기). AI가 할 수 있으면 하고, 못 하면 사용자에게 할 일 목록을 준다 |

시안 · 질문 결정은 사용자의 실제 답으로만 닫는다. AI가 사용자 대신 답을 채우지 않는다.

## 진행

1. 처음 세션: 도착점을 먼저 정한다. 그다음 갈래마다 한 단계씩만 들어가 전체를 훑어 열린 결정과 아직 못 정한 것을 적는다. 조사 결정은 바로 돌린다.
2. 이후 세션마다: 목록 파일을 읽고, 먼저 풀려야 할 결정이 모두 닫힌 열린 결정 하나를 고른다. 「맡은 세션」 칸을 먼저 채운 뒤 일한다. 조사 말고는 한 세션에 결정 하나만 닫는다.
3. 닫을 때:
   - 답을 적고 「정한 결정」에 한 줄 더한다.
   - 이 답으로 정확해진 항목을 「아직 못 정한 것」에서 열린 결정으로 옮긴다.
   - 도착점 너머로 드러난 항목은 범위 밖으로 옮긴다.
   - 이 답으로 틀어진 다른 항목을 고친다.
4. 열린 결정과 아직 못 정한 것이 모두 비면 정한 결정을 모아 명세를 쓰고, 명세로 작업 단위 계획을 세운다.

## 명세

결정이 여러 세션에 걸쳐 쌓인 일은 계획 앞에 명세를 둔다. 한 세션에 끝나는 일은 명세 없이 완성 모습과 계획으로 간다.

| 절 | 담는 것 |
|---|---|
| 문제 | 쓰는 사람이 겪는 곤란 |
| 해법 | 쓰는 사람이 보게 될 결과 |
| 쓰는 사람 이야기 | 「누가 · 무엇을 · 왜」를 빠짐없이 번호로 |
| 정한 결정 | 바꿀 부분 · 서로 넘길 약속 · 규칙. 파일 경로와 코드 조각은 넣지 않는다. 시안에서 나온 규칙 함수처럼 글보다 정확한 조각만 줄여 넣는다 |
| 확인 결정 | 어디서 무엇으로 확인하나. 이미 있는 가장 바깥 확인 지점 하나를 고른다 |
| 범위 밖 | 하지 않을 것과 까닭 |

작업 단위는 일이 끝나면 닫고, 명세는 그 단위들의 까닭을 남긴다. 오래 지킬 결정은 프로젝트 규칙 문서의 결정 기록으로 옮긴다.
