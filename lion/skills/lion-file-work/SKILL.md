# 파일 작업

기존 파일을 고치거나 바꾸거나 여러 파일을 만들 때 원본을 지키고, 결과를 다시 열어 그대로인지 확인한다.

## 함께 여는 스킬

이 스킬을 열면 아래 조건에 맞는 스킬을 일을 시작하기 전에 바로 함께 연다.

- 파일 형식의 규칙: 한글 `lion-hangul`, PDF `lion-pdf`, 슬라이드 `lion-ppt`, 엑셀·CSV `lion-spreadsheet`, Word·텍스트·EPUB `lion-document`, 로고·배너·이미지 `lion-visual-design`

## 바로 할 일

1. 편집 직전 파일과 변경 범위를 다시 읽는다. 처음 읽은 뒤 바뀐 내용이 있으면 병합하거나 충돌만 보고한다.
2. 대량 변경·유일본 덮어쓰기·손실 가능 변환 전에는 버전 이력이나 독립 사본으로 복구 기준점을 만들고, 사본의 크기·해시가 원본과 같은지 확인한다. 새 파일만 만드는 작업은 이 단계를 건너뛴다.
3. 형식이 담은 객체(표·그림·필드·수식·주석·매크로·차트)를 쓸 도구가 보존하는지 확인한다. 보존을 확인하지 못했으면 보존되는 도구를 쓰거나 원본은 그대로 두고 새 파일로만 낸다.
4. 작업 사본에서 편집하고 새 경로에 저장한다.
5. 교체 직전 원본이 처음 읽은 상태(해시)와 같은지 다시 확인한다. 달라졌으면 원본은 그대로 두고 검증한 결과를 별도 이름으로 남긴다.
6. 저장한 결과를 다시 열어 바뀐 범위의 내용과 범위 밖의 쪽·서식·값·객체가 그대로인지 대조한다. 쪽·슬라이드·차트가 있는 형식은 렌더링해 실제 모습을 본다.

- 파일이 열려 있는지는 실제 접근 상태와 동시 저장 가능성으로 판단한다. 잠금 파일은 근거로 쓰지 않고 그대로 둔다.
- 저장·교체가 막히면 검증한 편집본을 별도 이름으로 남기고 원본 상태를 보고한다.
- 백업·임시 파일은 최종 산출물과 다른 이름·위치에 둔다. 백업 정리와 설치 경로 변경은 사용자가 요청할 때만 한다.
- 보고에는 실제로 돌린 검사와 결과만 적고, 도구가 없거나 실패해 못 한 검사는 미검증으로 적는다.
