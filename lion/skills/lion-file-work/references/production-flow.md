# 제작 범위와 전달

## 전체 처리

- 전체 처리 요청이면 실제 파일·절·표·쪽·슬라이드 목록으로 누락을 확인한다. 서로 다른 역할의 단위는 각각 판단하고, 그대로 둘 단위도 내용을 읽고 정한다.
- 서식만 바꾼 단위를 내용 검토까지 마쳤다고 보고하지 않는다. 처리·보존·미검토 단위의 구분이 결과 이해에 필요할 때 밝힌다.
- 도구 출력이 잘린 파일은 "미열람"으로 남기고 나머지를 읽는다.

## 출력

- 같은 내용을 PDF·Word·Excel 등 여러 형식으로 내면 한 원본 자료에서 만든다.
- 편집 가능한 원본이 필요하거나 요청받았으면 미리보기와 함께 구조가 살아 있는 원본을 낸다.
- 목차는 변환기의 자동 목차와 본문에 쓴 목차 중 하나만 낸다.
- 부가 보고서·원장·별도 기록은 요청이나 실제 복구·추적 필요가 있을 때만 만든다. 기존 기록이 있으면 이어 쓴다.

## 표 기본값

사용자가 따로 정하지 않았을 때 쓴다.

- 같은 속성을 가진 항목이 셋 이상이면 표로 쓴다.
- 칸마다 값을 모두 적는다. 윗줄과 같은 값도 다시 적는다. 빈 칸은 값이 없다는 뜻으로만 쓴다.
- 굵기는 머리행·제목·합계에만 쓴다. 본문 값은 모두 같은 굵기로 두고, 눈에 띄어야 할 값은 색이나 비고 칸으로 표시한다.
