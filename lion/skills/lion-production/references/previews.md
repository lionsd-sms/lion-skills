# 시안

## 개수

| 요청 | 만드는 것 |
|---|---|
| "시안 N개" | 서로 다른 방향 N개. 기존 틀을 고른 경우 방향은 구성(첫 장면 여는 방식, 장 수, 강조 자리)이다 |
| "한 방향에서 문구만 N개" | 같은 방향 안에서 문구 N개 |
| "추천 하나면 돼" | 한 안과 까닭 |
| "시안은 필요 없어" | 시안 단계를 건너뛴다 |
| 개수 말 없음 | 2개를 제안하고 바꿀 수 있다고 한 번 알린다 |

비율이나 문구만 바꾼 변형은 방향 수에 넣지 않는다.

## 만드는 법

- 시안이 가를 결정(예: 첫 장면을 도식으로 열지 글자로 열지)을 먼저 한 문장으로 적는다. 가를 결정이 없으면 시안을 만들지 않고 추천 하나로 간다.
- 시안은 고르는 데만 쓰고 고른 뒤 버린다고 알린다. 고른 안은 구성표와 DESIGN.md 로 옮겨 처음부터 만든다.
- 같은 내용·자료·크기·완성도로 맞춘다. 차이는 구성, 위계, 움직임, 정보 양처럼 고르는 데 의미 있는 곳에 둔다.
- 빨리 보이는 수준으로 만든다. 전체 제작은 고른 뒤에 한다.
- 자료가 없는 자리는 임시 문구·자리 표시로 두고 표시한다. 숫자·기능·후기를 지어내지 않는다.
- 영상의 3~5초 견본은 짧게 렌더해 재생하거나, 전환 구간을 이동 길이의 1/5 이하 간격으로 프레임을 떠서 본다.
- 만들기 전에 가를 결정과 시안 범위를 한 줄로 알린다. 예: "첫 장면을 도식으로 열지 글자로 열지 가르려고 두 방향의 대표 장면을 한 장씩 만들고 첫 전환은 4초 견본으로 보이겠습니다. 임시 문구는 회색으로 표시합니다."

| 매체 | 시안 | 시안으로 볼 것 |
|---|---|---|
| 영상 | 대표 장면 그림 + 핵심 전환 3~5초 견본 | 구도, 이어짐, 빠르기, 읽을 시간 |
| PPT | 첫 장 + 핵심 메시지·자료가 든 장 | 한 장의 메시지, 위계 |
| 문서 | 대표 본문 쪽 + 표·그림이 많은 쪽 | 밀도, 표 모양, 읽힘 |
| 엑셀 | 머리행과 몇 줄이 든 작은 시트 | 입력 칸 구분, 수식 결과 |
| 이미지 | 실제 크기 구성안 | 피사체, 자르기, 글자 자리 |
| 소리 | 같은 문장의 짧은 청취 견본 | 발음, 속도, 음악과의 관계 |

## 보일 때

- 시안마다 다른 점을 한 줄씩 쓴다.
- 추천 하나를 까닭(목적에 맞는 점, 수정 비용)과 함께 표시한다.
- 확인한 것과 확인 못 한 것을 나눈다. 정지 그림으로 움직임을 확인했다고 쓰지 않는다.
- 사용자가 둘을 섞자고 하면 섞을 칸을 DESIGN.md·구성표 칸 이름으로 적어 확인받는다.

완료: 사용자가 하나를 골랐고, 고른 안과 까닭이 요청서나 수정 기록에 남았다.
