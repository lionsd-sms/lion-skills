# 소셜 이미지와 배너

## 소셜 이미지 만들기

- 게재 위치·수량이 미정이면 Instagram Post 1:1 + Story 9:16, 3변형을 시작안으로 제안하고 확정한 범위만 만든다.
- 확정한 아이디어·크기 조합마다 정확한 픽셀 크기의 HTML 한 파일을 만들고 스크린샷으로 PNG를 낸다. 파일 이름에 아이디어·플랫폼·종류·크기를 넣는다.

```
output/social-photos/
├── idea-1-instagram-post-1080x1080.html
├── idea-1-instagram-story-1080x1920.html
└── exports/idea-1-instagram-post-1080x1080.png
```

- 뷰포트를 목표 픽셀 크기로 맞추고 스크롤 없이 모든 요소가 보이게 한다.
- 1080px 폭에서 아래 최소 글자 크기를 쓴다.

| 요소 | 최소 크기(1080px 기준) | 굵기 |
|---|---|---|
| 제목 | 48px | Bold/Black |
| 부제목 | 32px | Semibold |
| 본문 | 24px | Regular |
| 캡션 | 18px | Regular/Light |
| CTA | 28px | Bold |

## 내보내기

- 캡처 전에 `document.fonts.ready`와 모든 이미지의 `decode()`가 끝났는지 기다린다. 준비 신호를 못 받을 때만 제한된 고정 지연을 쓴다.
- 브라우저 배율(`deviceScaleFactor`)을 2로 두면 PNG가 목표의 2배 크기로 나온다. 플랫폼 규격에 맞는 배율을 고르고, 내보낸 PNG의 실제 픽셀 크기를 직접 확인한다.
- 내보낸 PNG는 `exports/` 아래에 두고, 재현에 필요한 HTML은 함께 보존한다.

## 안전 영역과 문구

- 핵심 문구·CTA는 게재 위치의 최신 잘림·안전 영역 규격을 확인해 그 안에 둔다. 중앙 면적 비율(70~80%)은 구성 참고값이며 이것만으로 안전 영역을 검증하지 않는다.
- 광고 문구는 한 줄 7단어·3줄 이내로 쓴다. 광고 텍스트 비율은 최신 플랫폼 정책으로 판단한다. 폐기된 20% 문구 규칙을 통과 조건으로 쓰지 않는다.
- 인쇄 배너의 DPI·도련·색 공간은 인쇄소 사양·물리 크기·시청 거리로 정한다. 보편적인 최저 DPI를 정하지 않는다.
