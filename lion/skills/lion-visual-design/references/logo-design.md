# 로고

## 만들 때

- 마스터는 투명 배경으로 만들고 사용 맥락에 맞는 밝은·어두운 배경 미리보기나 변형을 더한다.
- 생성한 PNG는 래스터라고 밝힌다. 벡터 납품이면 SVG 경로를 그리거나 벡터화한다. 벡터화한 SVG는 원본과 같은 크기로 겹쳐 모양이 어긋난 곳이 없고, 곡선이 짧은 꺾은선 조각으로 들쭉날쭉하지 않고, 내장 래스터가 없고, 16px과 1000px 이상에서 가장자리가 매끈해야 통과다.
- 16×16px 축소, 명함 크기, 단색·흑백에서 식별성을 확인하고 축소 때 사라지는 세부를 줄인다.
- 로고 안 글자에는 UI 텍스트 대비 기준을 적용하지 않는다. 브랜드 색을 UI 글자·컨트롤에 쓸 때는 그 대비 기준을 맞춘다.
- 기존 로고의 부분 수정은 요청한 파일과 변형에만 적용한다.

## 새 로고 납품 묶음

새 로고 체계는 합의한 사용처에 필요한 만큼 형태 넷 × 색 넷에서 골라 낸다.

| 형태 | 파일 이름 | 쓰는 곳 |
|---|---|---|
| 가로형 전체 | `logo-full-horizontal.{ext}` | 웹 머리, 문서 |
| 세로 쌓기 | `logo-stacked.{ext}` | 정사각 자리, 소셜 프로필 |
| 마크만 | `logo-icon.{ext}` | 파비콘, 앱 아이콘, 작은 자리 |
| 글자만 | `logo-wordmark.{ext}` | 마크가 이미 있는 자리 |

색: 원색(밝은 배경), 반전(어두운 배경), 단색 어둡게(색을 못 쓰는 밝은 배경), 단색 밝게(색을 못 쓰는 어두운 배경).

| 용도 | 형식 | 비고 |
|---|---|---|
| 웹 | SVG | 기본 |
| 웹 대체 | PNG | 투명 배경 |
| 인쇄 | PDF | 벡터 |
| 인쇄, 옛 시스템 | EPS | |
| 문서 | PNG | 300dpi |
