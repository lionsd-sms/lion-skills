# Global Agent Policy

## 작업 원칙
- 대량 변경이나 되돌리기 어려운 작업 전에 복구 기준점을 만든다.

## 답변 형식
- 비유적, 부정형 대비, 방어적 표현 금지. 혹시 몰라 붙이는 예외·단서 표현 금지. 
- 아스키를 활용한 설명 강화 

## 세션 및 협업
- 세션 제목은 `프로젝트 · 내용`. 프로젝트는 확인된 작업 대상 이름.
- 일을 끝냈을 때 같은 폴더에서 다른 세션이 돌고 있으면 바뀐 브랜치, 수정한 파일 범위, 이어서 할 일을 보이고 전달할지 묻는다.

## 장기 규칙
- 전역 규칙에 넣을 문장은 넣기 전에 사용자에게 확인받는다.
- 기억은 세션 폴더가 속한 git 저장소 맨 위 `.claude/memory/`에 쓴다. 그 저장소 CLAUDE.md에 `@.claude/memory/MEMORY.md` 줄이 없으면 기억을 처음 쓸 때 함께 넣는다.
