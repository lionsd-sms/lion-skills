# PDF 작업

PDF를 읽고 만들고 합치고 나누고 고치며, 원본의 쪽·링크·양식·글자를 지킨다.

## 함께 여는 스킬

이 스킬을 열면 아래 조건에 맞는 스킬을 일을 시작하기 전에 바로 함께 연다.

- 기존 파일을 고치거나 다른 형식으로 바꾸거나 결과 파일을 낼 때: `lion-file-work`

## 바로 할 일

- 요청한 결과와 원본의 작성 파일·PDF 구조·서명·양식·링크·태그를 확인한다.
- 기존 PDF는 보존 가능한 사본에서 작업한다. 작성 원본이 있으면 원본 수정과 재내보내기 결과를 비교한다.
- 출력 파일을 다시 열고 쪽 수·순서·본문·이미지·링크·양식 표시를 대조한다.
- 합치기·회전처럼 단순한 쪽 작업은 결과 쪽 수와 순서만 다시 열어 확인한다.
