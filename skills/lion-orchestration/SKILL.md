# 지휘

일을 크기에 맞게 직접 하거나 나눠 맡기고, 맡긴 결과를 합쳐 끝까지 책임진다.

## 함께 여는 스킬

이 스킬을 열었으면 파일을 읽거나 고치기 전에, 아래 조건에 맞는 스킬을 Skill 도구로 연다(Codex 는 그 스킬의 SKILL.md 를 읽는다). 이미 열려 있으면 건너뛴다.

- 영역이 둘 이상이거나 할 일이 셋 이상이라 나눠 맡기는 요청(끝 검수를 계획에 넣으려고 시작할 때 연다): `lion-review`

## 일 크기

신호를 보고 셋 가운데 하나를 고르고, 고른 크기와 까닭을 한 줄로 남긴다.

| 크기 | 신호 | 하는 방식 |
|---|---|---|
| 바로 | 바꿀 곳이 한두 파일, 50줄 안팎, 보안·데이터 삭제·저장 형식·설치와 권한 설정·배포가 아님 | 마스터가 직접 하고 바뀐 동작을 실제로 확인한다 |
| 맡김 | 결과는 짧은데 읽을 양이 많음(긴 로그, 저장소 전체 훑기, 외부 자료 조사) | 서브 하나가 읽고 요약만 돌려준다 |
| 지휘 | 완성 모습을 정해야 함, 영역이 둘 이상, 작업 단위가 셋 이상 | 기획 · 계획 · 실행 · 검수로 나눈다 |

```
마스터 ─ 사용자 대화 · 결정 · 통합 · 최종 확인 · 사용자 질문
 └ 단계 책임 ─ 그 단계의 실무 에이전트가 셋 이상일 때만 둔다
    └ 실무 에이전트 ─ 읽고 만들고 고친다
       └ 필요하면 한 단 더 (Claude Code 기본 중첩은 마스터 아래 3단)
```

마스터의 책임은 아래로 옮겨가지 않는다. 지휘에서 마스터는 지시서 · 합치기 · 판단을 맡고 만드는 몫은 실무 에이전트에게 준다. 스크립트 한 번으로 끝나는 반복 일은 나누지 않고 스크립트로 한다.

## 맡길 때

1. 맡김 지시서를 쓴다: 목적, 확정 결정, 기준 판본, 먼저 읽을 스킬, 읽을 자료 경로, 앞 단위 반환, 쓰기 범위, 범위 밖, 완료 기준, 확인 방법, 시간 한도, 반환 형식. 받는 쪽은 대화를 모른다고 보고 지시서만으로 일할 수 있게 쓴다. 파일에 있는 내용은 경로로 가리킨다. 먼저 읽을 스킬에는 이 몫에 맞는 스킬(검수 몫이면 작업에 쓴 스킬)의 SKILL.md 절대 경로를 적고, 검수 몫이면 검수 기준 문서도 넘긴다. 서브에는 세션 시작 때 도는 안내가 없어 여기 적지 않은 스킬은 열리지 않는다.
2. 대화에 lion 모델 시트(Claude `~/.claude/rules/lion-models.md`, Codex 는 AGENTS.md 의 같은 이름 절)가 실려 있으면 그 표를 출발점으로 삼는다. 모델과 노력을 판단 깊이 · 읽을 양 · 확인 쉬움 · 되돌리기 어려움으로 고르고 까닭을 한 줄 남긴다. 부를 때 값을 넘긴다: Claude 는 Agent 호출의 `model` · `effort` 칸, Codex 는 에이전트를 만들 때 모델 이름과 추론 노력.
3. 서로의 결과를 기다리지 않고 같은 파일·자원을 쓰지 않는 일만 병렬로 보낸다.
4. 역할 에이전트가 있으면 그 이름으로 부른다: 기획 `scoper`, 계획 `planner`, 실행 `executor`, 검수 `reviewer`, 조사 `researcher`. 2의 값은 늘 넘긴다.
5. 마칠 때는 합친 최종 판본에서 단계 사이 연결을 확인한다. 지휘 크기의 일은 끝에 작성에 끼지 않은 에이전트에게 검수를 한 번 맡기고(맡김 크기는 마스터가 돌려받은 결과를 실제 자료와 대조하고 끝낸다), 지적은 만든 쪽이 고친다. 다른 회사 AI 는 사용자가 원할 때만 읽기 전용으로 부른다.

반환 형식: 첫 줄 판정(끝남 · 일부 · 막힘, 검수는 역할 파일의 지적 판정), 바꾼 파일, 확인한 것(통과 · 문제 · 결론 못 냄), 남은 것, 필요하면 `올림:` 줄. 반환은 주장으로 보고, 결론을 가르는 부분은 실제 파일·명령으로 다시 확인한다. 올림 꼴은 `올림: 남은 것 · 양쪽 근거 · 추천 · 고르면 달라지는 것`이다. 받은 쪽은 시험·자료로 가릴 수 있으면 직접 정한다. 결과가 같은 내부 일은 진행하고 알린다. 보이는 결과·범위·취향·정책·비용이 달라지면 한 단 위로 올린다. 마스터는 사용자에게 추천을 첫째로 둔 객관식으로 묻고, 답을 기다리는 동안 그 답에 묶이지 않은 일을 계속한다.
