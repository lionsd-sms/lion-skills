# 설치 설정

이 PC 에 맞는 모델 시트를 만들어 대화마다 실리는 자리에 둔다. 서브 에이전트에게 일을 맡길 때 이 시트가 모델·노력의 출발점이 된다.

| AI | 시트 자리 |
|---|---|
| Claude | `~/.claude/rules/lion-models.md` (이 폴더의 파일은 대화마다 실린다) |
| Codex | `~/.codex/AGENTS.md` 안의 `<!-- lion-models 시작 -->` ~ `<!-- lion-models 끝 -->` 절 |

## 바로 할 일

1. 두 자리에 시트가 이미 있으면 읽어 지금 적힌 값을 보인다.
2. 쓸 수 있는 모델을 찾는다.
   - Codex: `~/.codex/models_cache.json` 의 `models` 에서 `slug` 와 지원 노력을 읽는다. 파일이 없으면 「Codex 없음」으로 적고 Codex 자리는 건너뛴다.
   - Claude: 지금 대화의 모델 이름을 적는다. 별칭 `haiku`·`sonnet`·`opus`·`fable` 가운데 이 계정에서 쓸 수 있는 것은 요금제마다 달라 사용자에게 묻는다.
3. 객관식으로 한 번에 묻는다(최대 넷, 추천을 첫째에): 쓸 수 있는 Claude 모델, Codex 를 서브로 쓸지, 비용 기준(아껴 · 보통 · 넉넉히), 가장 어려운 일에 쓸 모델.
4. 아래 출발점 표에서 시작해 답대로 옮긴다.
   - 비용 기준이 「아껴」면 모든 노력을 한 단 내리고, 「넉넉히」면 한 단 올린다. 노력 단계는 `low` < `medium` < `high` < `xhigh` < `max`.
   - 쓸 수 없는 모델 자리는 쓸 수 있는 것 가운데 가장 가까운 아래 모델로 채우고, 그 모델에 없는 노력은 가장 가까운 아래 수준으로 쓴다.
   - Codex 칸은 2번에서 찾은 실제 `slug` 로 채운다. 가벼운 모델 → 수집·변환, 일반 모델 → 구현·설계, 가장 강한 모델 → 핵심 판단에 둔다.

   | 일의 결 | Claude | Codex |
   |---|---|---|
   | 방법이 정해진 수집·분류·변환·대조 | `haiku` · `low` | 가벼운 모델 · `low` |
   | 기존 방식 안의 구현·문서·정리 | `sonnet` · `medium` | 일반 모델 · `medium` |
   | 요구 해석·설계·원인 탐색 | `opus` · `high` | 일반 모델 · `high` |
   | 상충 조건·숨은 반례·되돌리기 어려운 핵심 판단 | `fable` · `high` | 가장 강한 모델 · `high` |

5. 시트를 쓴다. 대화마다 실리므로 아래 꼴 그대로 15줄 안에 맞추고, 같은 답이면 몇 번을 돌려도 같은 글이 나오게 통째로 새로 쓴다.
   - Claude: `~/.claude/rules/lion-models.md` 를 통째로 새로 쓴다. 폴더가 없으면 만든다.
   - Codex: 넣을 절을 먼저 보이고 확인받은 뒤, `~/.codex/AGENTS.md` 의 두 표시 줄 사이만 바꾼다. 표시 줄이 없으면 파일 끝에 절을 더한다. 절 밖은 건드리지 않는다.

   ```
   <!-- lion-models 시작 -->
   ## lion 모델 시트
   서브 에이전트에게 일을 맡길 때 아래 표를 모델·노력의 출발점으로 쓴다. 만든 날 YYYY-MM-DD (lion-setup), 비용 기준 보통.
   쓸 수 있는 Claude: haiku, sonnet, opus, fable / Codex: 씀
   | 일의 결 | Claude | Codex |
   |---|---|---|
   | … 4줄 … |
   <!-- lion-models 끝 -->
   ```

6. 쓴 시트를 다시 읽어 보이고, 앞 시트와 달라진 줄을 알린다. 영구 기본 모델과 사용자 설정 파일(`settings.json`, `config.toml`)은 바꾸지 않는다.

끝 보고는 한 일 · 확인한 것 · 확인 못 한 것.
