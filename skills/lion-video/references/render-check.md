# 렌더와 검사

## 순서

1. 규격: 영상 정보 도구(예: ffprobe)로 길이, 해상도, fps, 전체 프레임 수, 영상·소리 트랙 수, 코덱을 재고 요청서·DESIGN.md 값과 맞댄다. 소리가 있으면 전체 크기(LUFS)와 최고점을 잰다.
2. 장면 정지 그림: 장면마다 머무는 구간 가운데 프레임을 한 장씩 뜬다.
3. 전환 구간: 이동·전환 구간은 이동 길이의 1/5 이하 간격(12f 이동은 2~3f, 18f 전환은 3f)으로 뜨고, 전환 앞뒤 여유 구간(경계 앞뒤 0.5초 안의 나머지)만 0.1~0.2초 간격으로 떠서 한 장의 묶음 그림으로 늘어놓는다. 큰 이동이 있는 장면 안 구간도 같은 방법으로 뜬다.
4. 소리: AI는 소리를 들을 수 없으므로 잰 값으로 본다. 내레이션 시작, 효과음, 박자 전환 시각을 무음 구간 찾기와 구간별 음량으로 재어 장면표 시각과 맞대고, 들어야 아는 것(발음, 억양, 목소리와 음악의 어울림)은 구간 시각을 짚어 사용자에게 듣고 확인받는다.
5. 고치고 다시 뜨기: 문제를 고치면 그 구간과 앞뒤 전환을 다시 떠서 본다.

## 볼 것

| 항목 | 보는 법 |
|---|---|
| 개체 이어짐 | 전환 묶음에서 이어받는 개체가 프레임마다 보이고 자리가 이어진다. 사라졌다 다른 자리에 새로 나타나면 실패다 |
| 가감속 | 이동 구간 묶음에서 앞 프레임 간격이 넓고 도착 쪽이 좁아진다 |
| 글자 | 잘림, 겹침, 의도하지 않은 줄바꿈, 글꼴 대체(네모·다른 글꼴) |
| 안전 구역 | 글자와 주인공 개체가 안전선과 세로 앱 가림 자리 밖으로 나가지 않는다 |
| 자막 띠 | 자막 자리에 다른 글자·개체가 없다 |
| 깜빡임 | 한두 프레임만 검게 또는 비게 찍힌 곳이 없다. 전체 프레임의 밝기 변화를 재서 튀는 프레임을 찾는다 |
| 머무름 | 문구가 읽는 시간만큼 머문다 |
| 강조 | 장면마다 강조색이 한 곳이다 |

## 건너뛰는 핑계와 반박 (SKILL.md의 둘에 더해)

| 핑계 | 반박 |
|---|---|
| 미리보기에서 봤다 | 미리보기와 렌더본은 다를 수 있다. 셰이더 전환·글꼴은 렌더본에서만 보이기도 한다 |
| 규격이 맞다 | 규격은 길이·크기·fps만 알려 준다 |
| 소리 크기를 쟀다 | 전체 크기 하나는 시각을 알려 주지 않는다. 시작 시각·무음 구간·구간별 크기를 따로 재고, 들어야 아는 것은 사용자 확인으로 넘긴다 |

끝 보고에는 뜬 구간(장면, 프레임 범위, 간격)과 잰 소리 값을 적고, 보지 않은 구간과 사용자가 아직 듣고 확인하지 않은 소리 구간은 확인 못 한 것에 적는다.
