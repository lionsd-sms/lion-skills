# Word·DOCX·DOC·ODT·RTF

## 형식

- DOC는 바이너리라 python-docx가 읽지 못한다. ODT·RTF·DOC는 변환 필터나 호환 프로그램의 읽기·쓰기·변환을 각각 확인한다.
- 한국어·영문·숫자 혼합은 설치 글꼴과 `ascii`·`hAnsi`·`eastAsia`·`cs` 네 선언을 확인하고 긴 표·줄바꿈에서 검증한다.
- 목차·각주·쪽 번호 필드는 넣는 것과 값 갱신이 다르다. 실제로 갱신한 경우에만 계산됐다고 보고한다.

## 도구 함정

- `Paragraph.text`나 셀 전체 텍스트 대입은 run 서식·링크·필드를 지운다. 기존 run·텍스트 노드를 고치고, 여러 run에 걸친 치환은 원문 위치와 서식 경계를 먼저 매핑한다.
- python-docx로 표 행을 XML에서 지울 때는 세로 병합 `vMerge`의 연속과 셀 내용을 먼저 확인하고, 지운 뒤 표 구조를 다시 검증한다.
- 주석·변경 추적은 ID·범위·작성자·필드 연결을 지원하는 도구로 처리한다. 일반 텍스트 변경은 변경 추적이 아니다.
- Word를 COM으로 다룰 때 본문의 셀 끝·쪽 나눔 제어문자는 기록 형식에 맞게 보존하거나 명시적으로 인코딩한다. XML 로그가 제어문자로 실패하는 것은 문서 손상이 아니다.
- 내용 길이가 바뀌면 이어지는 쪽 나눔·목차·쪽 번호까지 다시 확인한다.
