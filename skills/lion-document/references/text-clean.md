# 용어 일관성

문서 안에서, 또는 여러 문서에 걸쳐 같은 대상의 이름을 맞출 때 쓴다.

- 한 개념에는 한 용어를 쓴다. `장비 ID / 기기 번호 / Set 번호 / Set ID`처럼 섞여 있으면 기존 문서·제품·사용자 자료의 기준 용어 하나로 통일한다.
- 한 낱말에는 한 뜻만 둔다. 표의 칸 이름에서 자주 생긴다: 물건 이름 칸과 개수 칸을 둘 다 `품목`이라 부르면 `품목`·`품목 수`로 나눈다.
- 파일·기호·플래그·명령은 코드에 있는 실제 이름 그대로 쓴다.
- 통일이 정책·기능의 뜻을 바꾸면 통일 전에 확인받는다.
