# 한국어 AI 글의 티 1~8: 낱말

번호는 고정이다. 보고와 대조표에서 이 번호로 부른다. 항목마다 알아보는 법, 고치는 법, 예(고치기 전 → 고친 뒤)를 둔다. 예는 원문의 말투를 그대로 둔다. 사람도 자주 쓰는 꼴은 문턱값 표의 횟수를 넘을 때만 고친다.

### 1. '~할 수 있습니다' 남발
- 알아보기: 동작을 설명하는 문장마다 '~할 수 있다'가 붙는다.
- 고치기: 일어나는 일을 그대로 쓴다. 사용자가 고르는 일이나 실제 가능성을 따지는 자리에만 남긴다. 가능성·조건을 말하는 문장은 단정으로 바꾸지 않는다. 의학·법률·안전 안내의 '~할 수 있다'는 그대로 둔다.
- 예: `저장 버튼을 누르면 내용을 저장할 수 있습니다.` → `저장 버튼을 누르면 내용이 저장됩니다.`

### 2. 빈 꾸밈말과 힘주는 부사
- 알아보기: 다양한·효과적인·중요한·핵심적인·원활한·체계적인·효율적인·혁신적인·강력한·획기적인·손쉽게·간단히, 매우·굉장히·상당히·크게·확실히·정말. 지워도 뜻이 같다. 뜻이 같은 꾸밈을 겹쳐 쓴다(중요하고 핵심적인, ~로서의 역할과 기능).
- 고치기: 지운다. 겹친 꾸밈은 하나만 남긴다. 무엇이 어떻게 다른지가 필요하면 원문에 있는 대상·개수·수치로 쓴다. 절차 안내에서 '간단히·손쉽게·빠르게'는 지운다. 구어 글에서 글쓴이 말투인 '정말·진짜'(정말 그랬다니까)와 정도를 재는 부사(거의 두 배)는 둔다.
- 예: `PDF·HWP·DOCX 등 다양한 형식의 파일을 효과적으로 처리합니다.` → `PDF·HWP·DOCX 등의 파일을 처리합니다.` ('등'은 목록이 일부라는 뜻이라 남긴다.)

### 3. 번역투 짜임
- 알아보기: ~를 통해, ~에 대해(대한), ~에 있어서, ~로 인해, ~에 의해 ~되다, ~되어지다·보여지다·여겨지다, ~을 가지고 있다, ~하는 것이 가능하다, ~함에 따라, ~에서의·~으로의·~에의, ~를 필요로 한다, ~라고 알려진, 조사 없이 쌓은 명사(기술 발전 속도 가속화), 낱말마다 붙는 ~적.
- 고치기: ~를 통해 → ~로·~해서, ~에 대한 검토 → ~ 검토, ~을 가지고 있다 → ~이 있다, ~되어지다 → ~되다, ~에 의해 ~되다 → 하는 쪽을 주어로, 학교에서의 생활 → 학교 생활. ~적은 빼도 뜻이 같으면 뺀다. '~를 통해·~에 대해·~을 위해'와 '~되고 있다'는 사람 글이 더 자주 쓰는 말이라 티가 아니다. 한 문단에 한두 번이면 그대로 두고, 3번 넘게 몰릴 때만 일부 고친다. 실제 경로(터널을 통해)는 둔다.
- 예: `사용자 의견을 통해 문제점에 대한 개선이 이루어졌습니다.` → `사용자 의견을 받아 문제를 고쳤습니다.`
- 복수 '들' 남발: 사물·추상 명사에 붙은 '들'만 뺀다. 사람에 붙은 '들'(학생들)은 둔다. 예: `여러 파일들에서 오류들이 나왔습니다.` → `여러 파일에서 오류가 나왔습니다.`
- '~하게 되다·되었습니다': 결과를 남의 일처럼 쓴다. 예: `이번 달부터 새 양식을 사용하게 되었습니다.` → `이번 달부터 새 양식을 씁니다.`
- 대명사 그·그녀·그들·그것: 사람도 자주 쓴다. 받을 대상이 앞 두 문장에 없으면 명사로 되살리고(무엇인지 모르면 묻는다), 하나뿐이면 지우고, 여럿이면 명사로 다시 쓴다. 예: `김 과장이 보고서를 냈고, 그는 그것을 다시 고쳤습니다.` → `김 과장이 보고서를 내고 다시 고쳤습니다.`
- '~라는 것이다' 꼬리: 예: `핵심은 백업을 먼저 해야 한다는 것입니다.` → `백업을 먼저 해야 합니다.`

### 4. 일을 명사로 묶어 '진행·수행·실시'로 돌리기
- 알아보기: 확인 작업을 진행한다, 분석을 수행한다, 교육을 실시한다, 개선이 이루어졌다, 검토를 하도록 하겠다. 확대·강화·개선·확보·마련·구축 같은 두루뭉술한 동사와 '구조·기준·설계'가 한 글에 몰린다. '사고 능력·수행 능력'처럼 '~ 능력'이 3번 넘게 나온다.
- 고치기: 명사 속 동사를 꺼내 쓴다. 두루뭉술한 동사는 실제 동작으로 쓴다(지원을 확대 → 대상을 넓히고 예산을 늘린다). 원문에 그 동작이 없으면 두고 묻는다.
- 예: `데이터 정합성 검증 작업을 진행하였습니다.` → `데이터 정합성을 검증했습니다.`

### 5. 거창하게 '이다·있다' 말하기
- 알아보기: ~로 자리매김하다, ~의 역할을 하다, ~을 자랑하다, ~을 선보이다, ~을 갖추고 있다, 남발하는 ~을 제공하다, 발판·토대를 마련하다, 지평을 열다.
- 고치기: '이다·있다·준다·쓴다'로 쓴다. 이미 일어난 사실(딥러닝의 토대를 놓은 사람)은 둔다.
- 예: `이 도구는 현장 점검의 핵심 도구로 자리매김하고 있습니다.` → `이 도구는 현장 점검에 씁니다.`

### 6. 유행어와 추상 낱말
- 알아보기: 인사이트, 시너지, 솔루션, 패러다임, 생태계, 여정, 고도화, 내재화, 가치 창출, 측정 없는 최적화, seamless·robust·leverage.
- 고치기: 원문이 가리키는 실제 대상이나 동작을 쓴다. 그 분야나 사용자가 정한 용어로 쓰였거나 글의 주장을 이루는 낱말이면 둔다. 다른 비유로 바꿔 끼우지 않는다.
- 예: `결재 단계를 셋에서 둘로 줄여 업무 프로세스를 고도화하고 시너지를 창출합니다.` → `결재 단계를 셋에서 둘로 줄입니다.`

### 7. 같은 대상을 여러 이름으로 부르기
- 알아보기: 한 글에서 설정 화면·환경설정·옵션 창, 또는 장비·기기·디바이스가 같은 것을 가리킨다.
- 고치기: 이름 하나를 골라 끝까지 쓴다. 사용자, 기존 문서, 실제 화면이 쓰는 이름을 고른다. 한 낱말이 두 뜻으로 쓰이면 둘로 나눈다(품목·품목 수).
- 예: `설정 화면에서 값을 바꾼 뒤 환경설정 창을 닫으면 옵션이 저장됩니다.` → `설정 화면에서 값을 바꾼 뒤 설정 화면을 닫으면 값이 저장됩니다.`

### 8. 흐린 가리키는 말
- 알아보기: '이는·이를 통해·이러한'이 앞 문장 전체나 둘 이상의 대상을 가리킨다. '해당·본'이 남발된다.
- 고치기: 가리키는 대상의 이름을 다시 쓴다. '해당 기능·본 문서'는 이름이나 '이 기능·이 문서'로 쓴다. 대상이 분명한 '이는·이 점에서'는 사람도 쓰므로 한 문단에 3번 넘게 이어질 때 고친다.
- 예: `로그인과 동기화가 느립니다. 이는 서버 설정 때문입니다.` → `로그인과 동기화 모두 서버 설정 때문에 느립니다.` (원문이 둘 중 무엇을 가리켰는지 모르면 묻는다.)
