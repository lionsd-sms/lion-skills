# 그림으로 설명

핵심 원리와 사용자가 이해해야 할 관계를 큰 그림과 짧은 글로 풀어 한 페이지 HTML로 만든다.

## 함께 여는 스킬

이 스킬을 열면 아래 조건에 맞는 스킬을 일을 시작하기 전에 바로 함께 연다.

- 원문의 사실·숫자를 옮기거나 기존 파일을 고칠 때: `lion-file-work`

## 바로 할 일

1. 주제를 요청에서 찾고, 독자가 알아야 할 핵심 관계 몇 가지를 정한다. 주제가 없을 때만 하나 묻는다.
2. 대상의 이름과 정의를 먼저 쓰고, 가장 작은 완결 답을 첫 화면에 둔다. 부품이 셋 이상이면 그림 하나에 몰지 않고 부품을 하나씩 더한 연속 그림으로 쌓는다.
3. 인터넷 없이 열리는 한 파일로 짠다. 그림은 inline SVG나 CSS, 이름표는 짧게, 작은 화면에서도 읽히게, 색 외에 형태·글자로도 관계를 드러낸다.
4. 사실·수치·원인 관계를 근거에 맞춘다. 비유 없이 실제 부품과 동작을 큰 그림으로 한 부품씩 보인다(예: 주소창 → DNS 서버 → IP 주소가 돌아옴).
5. 저장한 HTML을 브라우저에서 열어 그림·글자·작은 화면 배치·조작·외부 자원 의존을 확인한다.
