# 검색 노출

누구나 들어오는 공개 웹(회사 홈페이지·공개 서비스 따위)을 새로 만들거나, 쪽을 더하거나, 주소 체계·쪽 제목과 설명·robots.txt·사이트맵·리다이렉트·오류 응답·렌더링 방식을 바꿀 때 쓴다. 사용자가 검색 노출을 말하지 않아도 쓴다. 사내 도구·로그인 뒤에서만 쓰는 화면·데스크톱 앱에는 쓰지 않는다.

## 공통

- 순위·색인·리치 결과·대표 이미지 노출을 약속하지 않고, 그것은 검색 엔진이 고른다고 결과 설명에 적는다. 검색 결과의 제목과 설명도 엔진이 title·description·오픈 그래프·본문·링크 글에서 골라 바꿀 수 있다고 적는다.
- 사이트맵 한 파일은 두 엔진이 모두 받도록 10MB 미만, 주소 50,000개 미만으로 나누고, 넘치면 사이트맵 인덱스로 묶는다.
- 제목·설명의 글자 수는 합격선이 아니다. 길이를 맞추지 않고, 같은 낱말 되풀이나 내용과 관계없는 검색어·홍보 문구를 넣지 않는다.
- 사이트 등록·소유 확인·사이트맵 제출은 사이트 주인 계정이 할 일이다. 소유 확인 태그·파일을 넣을 자리만 만들고 그 일을 사용자에게 넘긴 일로 끝 보고에 적는다.

## 네이버

- 서치어드바이저 소유 확인은 호스트 단위다. 그 호스트 뿌리의 meta 태그나 HTML 파일로 준비하고, 태그는 frame 밖 메인 쪽의 head 에 두며, 메인 쪽을 JavaScript·meta refresh 로 넘기지 않는다.
- 웹 서버·방화벽이 네이버 검색로봇(User-Agent `Yeti`)을 IP 대역으로 막지 않게 하고, 막아야 하면 robots.txt 로 막는다.
- robots.txt 가 HTML 로 오면 규칙이 무시될 수 있고, 5xx 면 모두 막음, 4xx 면 모두 허용으로 읽힌다. 200 과 text/plain 으로 응답하게 한다.
- 리다이렉트는 연속 5회를 넘기지 않고, 거치는 주소가 모두 수집될 수 있게 한다.
- 잠시 수집을 줄여야 하면 robots.txt 로 막지 않고 웹마스터도구 수집 설정의 트래픽 제한을 쓰게 한다.
- og:type·og:title·og:description·og:image·og:url 을 함께 단다. og:image 는 150×150 보다 크고 5,000바이트 이상이며 가로세로 비가 3:1 을 넘지 않는, 그 쪽만의 이미지로 하고 사이트 공통 로고·배너를 쓰지 않는다.
- 메인 쪽 title 은 상호·서비스 이름 같은 브랜드 이름으로 쓰고, 검색 노출만을 위해 자주 바꾸지 않는다.
- 새 글이 이어 올라오는 사이트는 본문 전체를 담은 RSS(item 1개 이상, 10MB 미만)를 사이트맵과 함께 제출하게 한다.
- 핵심 정보는 본문 텍스트로 쓴다.
- 네이버 AI 출처설명에서 빼 달라고 사용자가 정했을 때만 meta robots 에 nosourceinfo 를 넣는다.

## 구글

- 사이트맵의 lastmod 는 본문·구조화 데이터·링크가 실제로 바뀐 때만 바꾼다. priority·changefreq 는 구글이 쓰지 않는다.
- 모바일과 데스크톱이 같은 본문·제목·구조화 데이터·title·meta description·robots 메타 태그를 갖게 하고, 주요 내용을 사용자 동작 뒤에만 불러오지 않는다.
- 색인할 쪽의 원래 HTML 에 noindex 를 넣었다가 JavaScript 로 지우는 방식을 쓰지 않는다.
- 구조화 데이터의 필수 속성을 빠뜨리지 않고, 권장 속성은 적더라도 완전하고 정확하게 채운다. 검증 도구를 통과해도 노출이 보장되지 않는다고 적는다.
- keywords meta 태그, 본문 길이 목표, 도메인·주소 속 키워드, 하위 도메인과 하위 폴더 선택, 제목 요소의 개수와 순서를 구글 순위를 위해 고치자고 권하지 않는다.
- Core Web Vitals 점수가 좋아도 상위 노출이 보장되지 않고 관련성이 앞선다고 적는다.
- 구글 AI 검색 기능에 나오려고 llms.txt 같은 별도 파일이나 특수 마크업을 권하지 않는다. Google-Extended 를 막아도 구글 검색 노출·순위는 바뀌지 않는다.

## 확인할 것

- robots.txt·sitemap.xml·상태 코드·리다이렉트는 배포된 주소에서 실제 응답을 받아 확인하고, 받지 못하면 미확인으로 적는다.
- 검색 반영(네이버는 로봇이 방문한 뒤 최대 1주일, 구글은 몇 시간에서 몇 달)은 이번 일 안에서 확인할 수 없으니 미확인으로 남긴다.
