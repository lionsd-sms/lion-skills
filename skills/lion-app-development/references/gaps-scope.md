# 빠진 곳 찾기와 범위 경계

## 인접 누락

기능 하나를 요청받아도 그 기능의 진입·상태·저장·오류·복구처럼 직접 이어진 흐름을 함께 본다. 이것들은 요청 기능이 실제로 끝나는 데 필요한 곁 상태다.

예: 「고객 검색 추가」는 검색 입력과 함께 다음을 가볍게 확인한다.

```text
검색 결과 0건 상태
검색어 초기화
입력 지연·중복 요청
잘못된 검색어 처리
목록 필터와 충돌
검색 후 상세 진입
뒤로 왔을 때 상태 보존 필요 여부
```

## 구현 범위 경계

- 확정된 완성 모습과 사용자가 맡긴 범위 안의 빈틈만 구현한다: 요청한 핵심 흐름을 끝내는 필수 상태, 검증·오류·로딩·빈 상태·재시도 같은 완성도 결함, 같은 정책 안의 빠진 안전장치, 이미 있는 기능의 빠진 진입점.
- 새 업무 정책·역할·권한 체계·외부 연동·과금·큰 schema 변화·지속 운영 비용·제품 목적 확장은 급해 보여도 추천과 영향만 보이고 사용자 결정으로 남긴다.
