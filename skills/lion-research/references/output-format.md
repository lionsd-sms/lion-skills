# 결과 문서

## 꼴

md 한 장은 나중에 다시 열어 그대로 쓸 수 있게 쓴다. 파일 이름은 `조사-<주제>-<YYYY-MM-DD>.md` 꼴로 하고, 프로젝트에 이미 조사 기록의 이름 꼴이 있으면 그것을 따른다.

```markdown
# <주제>

조사한 날: YYYY-MM-DD

## 질문
<한 문장>
범위: 기간 … · 대상 … · 깊이 …

## 답
<두세 문장. 첫 문장이 질문에 대한 답.>
확신: <근거 정도 한 줄. 예: 핵심은 공식 문서로 사실, 수치 비교는 정의 차이로 추론.>

## 근거 표
| # | 주장 | 표시 | 출처(위치) | 날짜·판 | 1차·2차 |
|---|---|---|---|---|---|
| 1 | … | 사실 | 문서 이름, 깊은 링크 | 2026-03 갱신 · v2.3 | 1차 |

## 어긋난 출처
- <주장>: A는 …(출처), B는 …(출처). 무게: <어느 쪽, 근거>.

## 확인 못 한 것
- <질문 조각>: <어디서> <어떤 검색어로> 찾았고 <무엇이 없었다>. 알 만한 사람·기관: <있으면>.

## 찾아본 곳
- <갈래>: <검색어·연 문서·기간>, 결과 <있음·없음·건너뜀(까닭)>
```

## 쓰는 규칙

- 답은 근거 표에 있는 주장만으로 쓴다. 근거 표에 없는 내용이 답에 들어가면 표에 더하거나 답에서 뺀다.
- 답 문장의 말투는 그 주장의 표시와 맞춘다. 추론·가설은 추론·가설 말투로 쓴다.
- 「어긋난 출처」가 없으면 절을 지운다. 「확인 못 한 것」은 남긴다. 비어 있으면 빈 곳이 정말 없는지 한 번 더 본다.
- 숫자를 직접 계산했으면(증가율, 합계) 근거 표 아래에 계산식과 쓴 원숫자를 쓴다.
- 표·그림은 옮기지 않고 위치를 링크한다.
- 사용자가 이 조사로 무엇을 바꾸려 하면 끝에 「바꿀 때 볼 것」 절을 더한다: 지킬 것 · 바꿔도 되는 것 · 피할 것 · 위험.
