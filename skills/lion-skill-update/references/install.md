# 설치 반영

호출 시험을 통과한 판을 Claude와 Codex 설치본에 같은 판으로 반영한다. 반영은 사용자가 확인한 뒤 한 번에 한다.

## 1. 설치 위치

| AI | 사용자 스킬 | 프로젝트 스킬 |
|---|---|---|
| Claude | `~/.claude/skills/<이름>/` | `<프로젝트>/.claude/skills/<이름>/` |
| Codex | `~/.agents/skills/<이름>/` | `<프로젝트>/.agents/skills/<이름>/` |

- Windows에서 `~`는 `%USERPROFILE%`이다.
- 사용자가 프로젝트 스킬로 쓰고 있으면 그 자리에 반영한다.
- 같은 이름의 스킬이 다른 경로(옛 설치 위치, 백업 폴더)에도 읽히는 자리에 있으면 목록으로 보이고 정리할지 사용자에게 묻는다. 같은 이름이 두 번 읽히면 어느 판이 열릴지 정해지지 않는다.

## 2. 반영 전 확인

사용자에게 다음을 보이고 확인을 받는다.

- 바뀌는 스킬과, 스킬마다 달라지는 동작 한 줄.
- 호출 시험 결과 요약(문장 수, 통과 수, 남은 미달).
- 새로 생기는 스킬, 없어지는 스킬.
- 백업할 위치.

## 3. 백업

- 두 설치 위치의 해당 스킬 폴더를 통째로 날짜 붙은 백업 폴더에 복사한다(예: `~/.claude/backup/skills-2026-10-19-<이름>/`).
- 백업 폴더는 스킬 폴더(`skills/`) 밖에 둔다. 안에 두면 백업이 스킬로 읽힌다.
- 백업한 경로를 기록에 남긴다.

## 4. 설치본과 원본 맞대기

- 설치본을 지난번 반영한 판과 비교한다. 사용자가 설치본에서 직접 고친 내용이 있으면 원본에 옮길지 사용자에게 묻고, 답에 따라 원본에 넣은 뒤 반영한다.
- 원본 저장소가 없으면 한 설치본을 백업한 뒤 직접 고치고, 시험을 통과한 그 폴더를 다른 AI의 설치 위치에 같은 판으로 복사한다.

## 5. 복사

- 원본 저장소의 스킬 폴더에 든 배포 파일만 복사한다. 시험 문장·개발 기록은 복사하지 않는다.
- 새 판에서 지운 파일은 설치본에서도 지운다(백업에서 되돌릴 수 있다).
- 합쳐서 없어진 스킬은 두 설치 위치의 그 폴더를 백업한 뒤 치운다.
- 사람이 이름으로만 부를 스킬이면 Codex용 `agents/openai.yaml`이 스킬 폴더에 함께 들어갔는지 본다.

## 6. 같은 판 확인

- 원본, Claude 설치본, Codex 설치본의 파일 목록과 파일마다의 내용 해시가 모두 같다.
- 새 대화 하나씩(Claude, Codex)에서 `+` 문장 하나를 돌려 설치본의 스킬이 열리는지 본다.
- 결과를 기록한다: 반영한 판(원본 커밋이나 날짜), 두 위치, 백업 경로, 해시 비교 결과, 새 대화 확인 결과.

## 7. 모드 방식

모드 스킬 하나만 자동으로 열리고 나머지를 여는 저장소는 스킬 복사에 더해 아래를 맞춘다. 설정 파일은 사용자 확인 뒤에 바꾸고, 바꾸기 전 파일과 넣기 전 상태를 남겨 넣은 것만 걷을 수 있게 한다.

- 세션 시작 훅: 새 대화 첫머리에 모드 폴더의 `hook.md` 를 출력해 모드를 먼저 열게 한다. Claude 는 `~/.claude/settings.json` 의 `hooks.SessionStart`(Windows 는 Git Bash 로 `cat`), Codex 는 `~/.codex/hooks.json` 의 `SessionStart`(Windows 는 cmd 로 `type`).
- Codex 는 훅을 사용자가 새 대화의 `/hooks` 에서 한 번 신뢰해야 돈다. 훅 정의가 바뀌면 다시 신뢰한다. 이 단계를 사용자에게 알린다.
- Claude 는 모드가 설치본 스킬 폴더의 SKILL.md 를 파일로 읽으므로 그 폴더 읽기를 허용한다: `permissions.allow` 에 `Read(~/.claude/skills/**)`. 작업 폴더 밖 읽기는 묻는 쪽이다.
- 반영 뒤 새 대화(Claude, Codex)에서 훅 글이 들어오고, 모드가 열린 다음 대상 스킬의 SKILL.md 가 읽히는지 본다.
