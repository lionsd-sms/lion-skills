# 수치와 시각 표현

## 수치 대조

- 대표 입력, 0·음수·큰 값·결측, 기간 경계, 중복·취소·수정 사례에서 별도의 계산이나 원자료와 맞댄다. 만든 수식의 출력을 그대로 기대값으로 복사하지 않는다.
- 행 수·총량·식별값·값의 분포·단위·원본 연결을 함께 대조하고, 합계가 맞아도 행이 서로 바뀌지 않았는지 확인한다.

## 표 계산

- 가져오기와 내보내기 뒤 식별값·앞자리 0·긴 숫자의 정밀도가 유지되는지 확인한다.
- 정렬·필터·중복 제거·조인 전후의 행 수·키 집합·합계를 대조한다. 일대다 조인의 행 증가와 누락·중복 키를 검사한다.
- 원자료·계산·가정·결과를 나눠 두고 수식·참조로 연결한다. 상수는 이름 붙인 가정 칸에 둔다. 새 기록을 더하면 원본 표와 요약·차트의 참조 범위가 그 기록을 포함하는지 확인한다.

## 차트

- 편집 가능한 차트가 필요하거나 요청받으면 차트 개체로 낸다.
- 막대 차트는 0 기준선과 음수 범위를 함께 확인한다. 필터별 실제 최저·최고 집계가 표시 범위 안에 드는지 렌더링해 확인하고, 새 자료가 고정 범위를 넘으면 범위를 다시 맞춘다.
- 새로 고침과 선택 필터 변경 뒤 KPI·요약·차트가 같은 원자료 조건으로 함께 갱신되는지 선택값을 실제로 바꿔 확인한다. 수식·차트 개체가 있다는 것만으로 갱신 성공을 판정하지 않는다.

## 시각 표현

- 사용자가 정한 브랜드·서식·프로젝트 토큰을 먼저 확인한다. 업종 이름만으로 색·글꼴·스타일을 정답처럼 고르지 않는다.
- 앱 화면 전용으로 승인된 시안 선호를 문서·라벨·이미지 전체의 의무로 넓히지 않는다.
- 재미·심미 선호·현장 읽기성을 사람에게 실제로 확인하지 않았으면 그 경험을 검증했다고 쓰지 않는다.
