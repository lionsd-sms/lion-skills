# 틀 관리

틀은 다시 쓸 DESIGN.md 와 견본 묶음이다. 작업 폴더에 매체별 틀 목록이 있으면 그 목록과 자리를 쓰고, 없으면 처음 저장할 때 자리를 물어 만든다.

## 목록 칸

| 칸 | 적는 것 |
|---|---|
| 번호 | 틀마다 하나 |
| 이름 | 짧은 이름 |
| 한 줄 설명 | 어떤 느낌, 어디에 맞는지 |
| 쓰임 갈래 | 영상 / PPT / 문서 / 엑셀 / 이미지, 그 안의 갈래(설명, 광고, 보고) |
| 크기별 자리 | 크기마다 DESIGN.md·견본 파일 자리 |
| 견본 | 대표 그림 파일 |
| 만든 날 | 날짜, 고친 날 |

## 새 틀 추가

방금 만든 디자인을 틀로 저장할 때는 1~3단계(쓰임·방향·DESIGN.md)를 건너뛰고 쓰임만 확인한 뒤 4단계 견본부터 한다.

1. 쓰임: 어디에, 누가 보는지, 크기, 길이, 자주 나오는 장면·장을 정한다.
2. 방향: 참고 자료를 받아 가져올 것과 버릴 것을 적는다. 목록에서 겹치는 틀을 찾아 있으면 "N번과 비슷한데 고칠까요, 새로 만들까요?" 묻는다.
3. DESIGN.md: 새로 만들기 질문지로 값을 채운다([디자인](design.md)).
4. 견본: 장면·장 역할(시작, 설명, 강조, 끝)마다 짧은 견본과 실제 주제 하나로 만든 견본을 크기마다 만든다.
5. 검사: 잘림, 겹침, 안전 구역, 빠른 깜빡임, 글자 대비를 확인한다. 다른 실행을 쓸 수 있으면 같은 항목을 검수받고, 없으면 만든 쪽이 항목별 증거 그림을 보인다.
6. 확인: 사용자가 견본을 보고 승인한다.
7. 등록: 번호·이름·한 줄 설명·크기별 자리·견본 그림을 목록에 더한다.

완료: 목록에 새 줄이 있고, 줄이 가리키는 파일이 모두 있다.

## 틀 수정

1. 먼저 묻는다: "이번 결과물만 바꿀까요, 틀 자체를 바꿀까요?"
2. 이번만이면 작업 안의 DESIGN.md 만 고친다.
3. 틀 자체면 그 틀로 진행 중인 작업을 찾아 알리고, 그 작업에 반영할지 묻는다.
4. 값 몇 개가 바뀌면 같은 번호로 고치고 고친 날을 적는다. 분위기·주인공 도형·전환 방식처럼 인상이 바뀌면 새 번호로 만든다.
5. 견본·검사·확인을 다시 거친다. 옛 판은 이력에 남긴다.

## 틀 빼기

목록에서 숨김으로 표시하고 파일과 이력은 남긴다. 그 번호는 다시 쓰지 않는다.
