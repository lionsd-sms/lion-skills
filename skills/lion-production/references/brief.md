# 요청서 질문

요청서는 사용자만 아는 것을 담는다. 색·글꼴·움직임 같은 제작값은 여기서 묻지 않고 디자인 단계에서 정한다.

## 묻는 법

- 한 번에 넷까지 묶어 묻는다. 결과의 목적·사실·만드는 수단을 바꾸는 질문을 먼저 한다.
- 질문마다 보기 2~4개와 추천 하나를 붙이고, 추천에 까닭을 한 줄 쓴다. 보기 끝에 "추천해줘"를 둔다.
- 대화·첨부 자료·이전 기록에서 답이 나온 칸은 옮겨 적고 묻지 않는다.
- "이 묶음은 추천대로"면 그 묶음을 추천 값으로 채우고 다음 묶음으로 간다. "세부는 맡길게"면 그 범위를 추천으로 채우고 까닭을 적는다.
- 사용자가 생각하지 못한 조건이 보이면 확인할 것, 결과에 주는 영향, 추천을 함께 보인다. 예: 홈페이지 자동재생에도 쓰면 소리 없이도 뜻이 통하게 첫 화면과 자막을 먼저 정하자고 제안한다.
- 조건이 충분한 요청은 빈 칸만 확인하고 다음 단계로 간다.

## 공통 칸

| 칸 | 묻는 말 | 보기 예 |
|---|---|---|
| 목적 | 이걸 본 사람이 무엇을 하게 할까요? | 이해 / 신청 / 구매 / 결재 / 기억 |
| 보는 사람 | 누가 보나요? 무엇을 이미 아나요? | 사내 실무자 / 고객 / 임원 / 처음 보는 사람 |
| 쓰는 곳 | 어디에 올리거나 띄우나요? | 유튜브 / 쇼츠 / 회의실 화면 / 인쇄 / 메일 첨부 |
| 자료 | 꼭 쓸 사진·로고·문구·숫자가 있나요? | 파일 있음 / 문구만 있음 / 없음 |
| 마감 | 언제까지, 비용은 어디까지? | 오늘 / 이번 주 / 무료만 / 유료 가능 |

자료 칸에는 바꾸면 안 되는 문구(확정 원문), 넣지 말 것, 확인이 필요한 숫자·이름·날짜를 따로 적는다.

## 매체 칸

| 매체 | 칸 | 보기 예 |
|---|---|---|
| 영상 | 길이 | 15초 / 30초 / 1분 / 3분 이상 |
| 영상 | 목소리 | 본인 목소리 / 합성 음성 / 자막만 |
| 영상 | 표현 방식 | 도형·글자 움직임 / 실사 / 화면 녹화 / 사진 엮기 / 섞기 |
| PPT | 발표 시간 | 5분 / 10분 / 20분 / 읽는 자료(발표 없음) |
| PPT | 장 수 | 시간에 맞춤(추천) / 정해진 수 |
| 문서 | 쪽 수 | 1쪽 / 5쪽 안 / 정해진 수 |
| 문서 | 제출 양식 | 회사 양식 있음 / 자유 / 기관 지정 양식 |
| 엑셀 | 누가 입력 | 나만 / 여러 사람 / 다른 시스템에서 가져옴 |
| 엑셀 | 무엇을 계산 | 합계·집계 / 기한·상태 / 단가·금액 / 계산 없음 |
| 이미지 | 크기 | 정사각 / 세로 / 가로 / 인쇄 규격 |
| 이미지 | 쓰는 곳 | SNS / 배너 / 인쇄물 / 문서 삽입 |

받을 파일 칸(파일 형식, 다시 고칠 원본이 필요한지)은 매체와 상관없이 마지막 묶음에서 묻는다.

## 결정 상태

| 상태 | 적는 것 |
|---|---|
| 확정 | 사용자 답이나 고른 안 |
| 추천 | 추천 값, 까닭, 다른 보기를 고르면 바뀌는 것 |
| 미정 | 사용자만 정할 수 있는 것과 필요한 까닭 |
| 시험 뒤 결정 | 시안이나 작은 시험으로 정할 것과 확인 방법 |

칸마다 근거(사용자 답, 자료, 이전 기록, 추정)를 붙인다. 빈 틀은 [요청서](../templates/요청서.md).
