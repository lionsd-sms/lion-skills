# 스프레드시트

엑셀·CSV·TSV 표를 만들고 고치고 분석하며, 수식과 값을 다시 계산해 확인한다.

## 함께 여는 스킬

이 스킬을 열면 아래 조건에 맞는 스킬을 일을 시작하기 전에 바로 함께 연다.

- 기존 파일을 고치거나 다른 형식으로 바꾸거나 결과 파일을 낼 때: `lion-file-work`

## 바로 할 일

- 작업 폴더에 요청서·DESIGN.md·구성표가 있으면 그 값 이름과 확정 문구를 그대로 쓴다.
- 열과 값의 뜻, 식별자·단위·빈값·계산 조건을 먼저 정한다.
- 기존 통합 문서는 수식·시트·차트·정의 이름·서식과 연결을 보존하며 사본에서 고친다.
- 가져오기·내보내기에서는 앞자리 0, 긴 숫자, 날짜, 수식처럼 보이는 문자열의 자료형을 확인한다.
- 수식은 계산 엔진으로 재계산하고 독립 기대값·경계값과 대조한다. 인쇄·차트·대시보드는 실제 화면과 출력에서 확인한다.
- 작은 수정(셀 몇 곳, 수식 하나)은 해당 부분만 고치고 재계산해 확인한다.
